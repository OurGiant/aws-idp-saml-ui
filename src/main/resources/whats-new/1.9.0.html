Version 1.9.0

Easier to get started

  • A new setup wizard. First-run setup is now a few short steps: connect to your identity provider, then add your AWS accounts. Adding accounts is optional; skip it and add them later.
  • Import your accounts instead of typing them. In the wizard, Import from your identity provider signs in once and lists every AWS role you have to tick. You can also add one account by hand.
  • Start from your team's profile file. Choose Import a profile file from my team on the first screen to use a file exported with File → Export Profiles.
  • Test Sign-in checks your identity provider details before you go on, and keeps the roles it finds so you don't have to sign in twice.
  • Detect the login page title. Click Detect... next to Login page title and the app opens your login page and fills it in, so there's nothing to guess.
  • Always a next step. With no accounts yet, the main window shows what to do: add an identity provider, import from it, add a profile, or import a profile file.

Manage identity providers

  • File → Identity Providers lists your identity providers and how many profiles use each. Add, edit, rename, duplicate and delete them without editing ~/.aws/samlsts, and choose the default for new profiles.
  • Renaming is safe. Every profile that uses the provider is updated with it. The editor shows the IAM provider ARN as you type, since the name has to match the SAML provider in IAM.
  • Deleting is safe. If profiles still use the provider, you choose whether to move them to another one or delete them too.
  • Identity providers are shown by name everywhere, e.g. CorpOkta rather than Fed-CorpOkta.

Settings

  • Username and default region can now be changed in File → Configuration. Before, they could only be set during first-run setup.

Also new since 1.8.0

  • Choose a region from a list in Manage Profiles → Edit, with names like US East (N. Virginia), instead of typing it.
  • Import from IdP shows account aliases when AWS provides them, and suggests profile names based on them.
  • With Show browser ticked, the browser lands on the profile's Open Console to page after sign-in.

Fixes

  • Editing a profile that uses the default identity provider no longer switches it to a different provider when you save.
  • The session duration chosen during first-run setup now takes effect.
  • Sign-in errors about a missing or incomplete identity provider now say where to fix it.
