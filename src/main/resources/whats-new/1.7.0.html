Version 1.7.0

Set up profiles faster

  • Import from your identity provider. In Manage Profiles → Import from IdP..., log in once and every AWS role you're granted is listed. Tick the ones you want; no more looking up account numbers and role names.
  • Export and import profiles. File → Export Profiles... saves your profiles and settings to a file you can import on a new machine or share with your team. The file never contains credentials or passwords, and importing never overwrites your existing profiles without asking.
  • Clearer "role not found" errors. If a profile's role isn't available to you, the error now lists the roles you do have, with the likely match highlighted.

Work from the tray

  • Tray quick actions. Pinned profiles now appear in the tray menu, with their status, plus Request Credentials and Open Console, and you can refresh expiring profiles without opening the window.
  • Remembers your window. The main window reopens where you left it, at the same size, maximized if it was.

Use your credentials anywhere

  • Ready-to-paste shell commands. Show Credentials can format credentials for bash/zsh, PowerShell or Command Prompt. Copy to Clipboard now copies only the commands.
  • AWS CLI region set up for you. When a profile has no region in ~/.aws/config, one is added so aws --profile <name> works right away. Nothing else in that file is changed, and you can turn this off in Configuration.
  • Copy Account Number from the status table's right-click menu.

Troubleshooting

  • View Logs (Help → View Logs...) shows the app's log and a startup log. If the app ever fails to start, it now tells you where the details were written.
  • The new Help menu also has these release notes and a link to every past release.

Fixes

  • Refresh Expiring/Expired Profiles and auto-renew pinned profiles now also renew profiles that have already expired. Previously only ones about to expire were picked up.
  • Roles from identity providers that list the provider before the role (such as ADFS) are now read correctly.
