Version 1.8.0

Use your credentials everywhere

  • AWS CLI, SDKs and Terraform can get credentials from the app. Right-click a profile and choose Copy AWS CLI Setup..., then paste the two lines into ~/.aws/config. Tools then fetch the profile's current credentials on demand, and tell you to refresh them here when they expire.
  • Check Identity. Right-click a profile to ask AWS who its credentials belong to: the account, role and full ARN, with a warning if they're for a different account than the profile expects.
  • Open Console where you work. In Manage Profiles → Edit, give a profile a region and choose a service under Open Console to (EC2, S3, CloudWatch and more) and it opens right there.

Manage profiles faster

  • Duplicate a profile in Manage Profiles to add a sibling role in the same account in seconds.
  • Session duration per profile. Each profile can use the global default or its own duration.
  • Import from IdP now shows which roles are already Present, and every column can be sorted.
  • GUI Name column. Right-click a column header in the status table to show each profile's friendly name. The filter box matches GUI names too.

Stay ahead of expiry

  • Countdowns on the tray icon. Hover it to see how long your pinned profiles have left, e.g. dev: 42m left · prod: expired.
  • Choose your warning time. Under Warn when credentials expire within in Configuration, pick 5, 10, 15 or 30 minutes. It sets when profiles turn amber, when you're notified, and when auto-renew kicks in.

Shared computers

  • Clear credentials. Right-click a profile to remove its credentials without deleting the profile, or use Actions → Clear All Credentials. Turn on Clear credentials when the app exits in Configuration to do it automatically. Entries you added to ~/.aws/credentials yourself are never touched.

Fixes

  • After dragging a column header to reorder the status table, clicking a row, Refresh Selected and drag-to-pin now act on the right profile.
